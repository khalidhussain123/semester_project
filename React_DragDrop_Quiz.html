⚛️ React Fundamentals
JSX, Components, Props, State, Virtual DOM, Conditional Rendering, Lists & Keys.

📘 Key Concepts

  • Component names MUST start with Capital Letter — lowercase = plain HTML tag.
  • JSX compiles to React.createElement() via Babel. All tags must be closed.
  • Props flow parent → child only (one-way data binding). Props are read-only.
  • Use className not class, htmlFor not for in JSX.
  • Lists must have a unique key prop on each item to help React reconcile the Virtual DOM.
  • ⚠ TRAP: useState uses array destructuring — const [x, setX].
  • Conditional render: use && for show/hide, ternary ? : for if/else UI.

🪝 Hooks & Effects
useState, useEffect, useRef, useContext, useMemo, useCallback — deep dive.

📘 Key Concepts

  • useEffect(fn, []) — runs once on mount (like componentDidMount).
  • useEffect(fn, [dep]) — runs on mount + whenever dep changes.
  • useEffect(fn) — runs after every render.
  • Return a cleanup function inside useEffect to unsubscribe/clear timers.

🏪 Redux & State Management
Redux Toolkit, actions, reducers, store, useSelector, useDispatch.

📘 Key Concepts

  • Redux: single store → action dispatched → reducer returns new state.
  • Reducers must be pure functions — no side effects, no mutation.
  • createSlice (Redux Toolkit) generates action creators + reducer automatically.
  • useSelector reads state from the store. useDispatch sends actions.
  • configureStore replaces the old createStore — includes Redux DevTools automatically.
  • ⚠ TRAP: Never mutate state directly in a reducer — always return a new object (RTK uses Immer to allow "mutating" syntax safely).

🚀 Express.js
Routing, middleware, req/res, REST APIs, error handling.

📘 Key Concepts

  • app.get/post/put/delete(path, handler) — define routes.
  • Middleware: app.use(fn) — runs on every request. Order matters!
  • req.params — URL params (/users/:id). req.body — POST body. req.query — query string.
  • res.json() sends JSON. res.status(404).json() sets status + sends JSON.
  • express.json() middleware parses incoming JSON bodies — required before req.body works.
  • ⚠ TRAP: Error-handling middleware has 4 params: (err, req, res, next).

📝 React Forms & Validation
Controlled components, onChange, onSubmit, validation, useForm patterns.

📘 Key Concepts

  • Controlled component: input value is driven by React state via value + onChange.
  • Always use e.preventDefault() in form submit handler — stops page reload.
  • onChange={(e) => setState(e.target.value)} — read value from e.target.value.
  • Checkboxes use e.target.checked, not e.target.value.
  • Client-side validation: check state before submitting; show error messages in state.
  • ⚠ TRAP: Never use document.getElementById for form values in React — use state.
